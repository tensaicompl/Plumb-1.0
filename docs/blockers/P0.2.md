`cargo check --workspace` fails building `libsqlite3-sys` (pulled in by the plan-mandated `rusqlite = { version = "0.32", features = ["bundled"] }`). The Rust `cc` build helper invokes `cc ... --target=x86_64-unknown-linux-gnu ... -c sqlite3/sqlite3.c`, and Zig's `cc` rejects that target spelling:

```text
error: unable to parse target query 'x86_64-unknown-linux-gnu': UnknownOperatingSystem
```

Diagnostics (run outside the repository):

- `cc --target=x86_64-unknown-linux-gnu -c t.c` → exit 1 with the error above
- `cc --target=x86_64-linux-gnu -c t.c` → exit 0
- `rustc +1.98.1 h.rs` (linking through `cc`) → links and runs

So the installed `cc` compiles and links, but is not compatible with the Rust-standard target-triple argument used by native build scripts. The plan §5.0 requirement ("a working C compiler/linker available through the command `cc`") is therefore not met for the Cargo build.
