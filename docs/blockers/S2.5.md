## Exact blocking fact

Hotfix 038 requires `crates/plumb-expr/src/lib.rs` to declare the S2.5 modules and expose the S2.5 API:

- S2.5 allowlist: `lib.rs`, `typecheck.rs`, `eval.rs`, `calendar.rs`, `render.rs`;
- §178: export `TypeEnv`, `TypeCheckError`, `typecheck`, `CalendarProvider`, `StaticCalendarProvider` and the rest.

So `lib.rs` must contain `mod typecheck;` and the names `TypeEnv` and `CalendarProvider`.

The accepted S2.4 integration test `crates/plumb-expr/tests/parser.rs::parser_source_guard` scans `lib.rs`, together with the S2.4 syntax modules, and asserts that it does **not** contain the tokens `typecheck`, `TypeEnv` or `CalendarProvider`. The test was written when S2.4 was required to have no type checker yet. With the required S2.5 `lib.rs` it fails:

```text
thread 'parser_source_guard' panicked at crates/plumb-expr/tests/parser.rs:846:13:
lib.rs contains typecheck
```

Hotfix 038 §177 forbids modifying `tests/parser.rs` ("unless a genuine Hotfix 038 contradiction is discovered. If so: BLOCK"), and `tests/parser.rs` is not in the S2.5 allowlist. The only way to pass the guard without editing it would be to hide the tokens, for example `#[path = ...]` module renames or aliasing the exports. That would circumvent a guard and is not done.

Everything else in the S2.5 contract was implemented and verified before stopping:

- `cargo test -p plumb-expr --test eval`: 20 run, 20 passed, 0 failed. This includes the HR working_days/days_between tables, the rounding table and spec strings, renderer snapshots, the HR half-day result `0.5 working_day`, and 512-case properties for well-typed evaluation, unit mismatch, the working-days bound and short-circuiting.
- `cargo test -p plumb-expr --no-fail-fast`: 37 passed, 1 failed (`parser_source_guard` only).
- `cargo test --workspace --no-fail-fast`: 843 passed, 1 failed (the same test).
- `cargo fmt --check` and `cargo clippy --workspace --all-targets -- -D warnings` are clean.
- No diff to Cargo files, the S2.4 modules (`ast.rs`, `types.rs`, `parser.rs`, `grammar.pest`), `tests/parser.rs`, other crates, fixtures or rules.
